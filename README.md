# Daily Web Dev Practice 🚀

A beginner-friendly repository for building small web development projects consistently.

## Project of the Day: Quick Text Tools

A lightweight browser-based tool that helps you:
- Count words and characters
- Estimate reading time
- Convert text to uppercase or lowercase
- Copy text with one click
- Clear the editor quickly

## Run locally
Open `index.html` in your browser. No dependencies or installation required.

## Tech stack
- HTML
- CSS
- Vanilla JavaScript

## Learning notes
This project practices DOM manipulation, event handling, string methods, responsive CSS, and clipboard access.
